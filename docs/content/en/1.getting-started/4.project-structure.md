`brutils` is a [pnpm](https://pnpm.io/) workspace managed with [vite-plus (`vp`)](https://viteplus.dev/guide/), which wraps building, testing, linting, and formatting in a single CLI.

## Monorepo layout

```bash
brutils/
├── packages/
│   ├── core/                # @brutils/core — the main library
│   └── react/               # @brutils/react — React adapters and hooks
├── docs/                    # @brutils/docs — this documentation site (Docus + Nuxt 4)
├── examples/                # Standalone usage examples
├── scripts/                 # Repo-wide scripts
├── pnpm-workspace.yaml      # Workspace + catalog definitions
└── package.json             # Root scripts and dev dependencies
```

## `packages/core/`

The core library. Public API is built around feature **modules** under `src/utilities/`.

```bash
packages/core/src/
├── common/                  # Shared helpers (e.g. assert-options, progressive-format)
├── utilities/
│   ├── cpf/
│   │   ├── constants.ts     # Regexes, lengths
│   │   ├── types.ts         # Error codes, option/result interfaces
│   │   ├── utils.ts         # assertValid + the module's Error class
│   │   ├── cpf.ts           # Public API: validate, format, generate, ...
│   │   └── index.ts         # Re-exports the module's public surface
│   ├── cnpj/
│   ├── cep/
│   └── ufs/
└── index.ts                 # `export * as cpf from "./utilities/cpf/index"` etc.
```

Every module follows the same shape: a strict `assertValid()` helper, a typed `Error` subclass with a `code` union, and public functions that prefer returning result objects over throwing.

## `docs/`

This site. A [Docus](https://docus.dev) (Nuxt 4) project with internationalization configured for English and Brazilian Portuguese.

```bash
docs/
├── content/
│   ├── en/                  # English content
│   └── pt-BR/               # Brazilian Portuguese content
├── public/                  # Static assets
├── nuxt.config.ts           # Nuxt + i18n config
└── package.json
```

## Tooling: `vp`

Common commands from the repo root:

| Task                                        | Command             |
| :------------------------------------------ | :------------------ |
| Install dependencies                        | `pnpm install`      |
| Run the docs site in dev mode               | `pnpm dev`          |
| Format the codebase                         | `pnpm format`       |
| Lint + workspace tests                      | `pnpm test`         |
| Full validation (fmt + lint + test + build) | `pnpm ready`        |
| Build every package                         | `pnpm -r run build` |

Inside `packages/core/`:

| Task                      | Command           |
| :------------------------ | :---------------- |
| Run all tests             | `vp test`         |
| Run a single test pattern | `vp test cpf`     |
| Build the library         | `vp pack`         |
| Watch + rebuild on change | `vp pack --watch` |
| Manual type-check         | `tsc --noEmit`    |

## Imports

Always import from `vite-plus` rather than from raw dev dependencies:

```ts
import { defineConfig } from "vite-plus";
import { expect, test, vi } from "vite-plus/test";
import { defineConfig } from "vite-plus/pack"; // tsdown.config.ts
```
