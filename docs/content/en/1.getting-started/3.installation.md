## Install `@brutils/core`

::code-group

```bash [pnpm]
pnpm add @brutils/core
```

```bash [npm]
npm install @brutils/core
```

```bash [yarn]
yarn add @brutils/core
```

::

## Requirements

- **Node.js** `>= 24.13.1` (matches the brutils monorepo engines requirement).
- **TypeScript** `>= 5` recommended. `@brutils/core` ships type definitions out of the box.
- **ESM**. The package is ESM-only (`"type": "module"`).

## Quick example

```ts [example.ts]
import { cpf, cnpj, cep, ufs } from "@brutils/core";

const result = cpf.validate("123.456.789-09");
if (result.success) {
  console.log("Valid CPF");
} else {
  console.log("Invalid:", result.error.code);
  //                                 ^? "INVALID_FORMAT" | "REPEATED_DIGITS" | "INVALID_CHECKSUM" | "UNKNOWN_ERROR"
}

const masked = cnpj.format("12345678000195"); // "12.345.678/0001-95"
const generated = cpf.generate({ formatted: true }); // e.g. "123.456.789-09"
const sp = ufs.get("SP"); // { name: "São Paulo", region: "Sudeste", ... }
const validCep = cep.validate("01310-100");
```

## Working on the monorepo

If you're contributing to brutils, clone the repo and install with pnpm:

```bash [Terminal]
git clone https://github.com/youphenrique/brutils.git
cd brutils
pnpm install
```

The monorepo is managed with [pnpm workspaces](https://pnpm.io/) and [vite-plus](https://viteplus.dev/guide/). To run the documentation site locally:

```bash [Terminal]
pnpm dev
```

This runs the `dev` script of `@brutils/docs` (this site) and serves it at <http://localhost:3000>.
