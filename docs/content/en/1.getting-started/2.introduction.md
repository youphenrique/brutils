Welcome to **brutils**, the essential Brazilian toolkit for the modern web.

## What is brutils?

`brutils` is a TypeScript monorepo of utilities for Brazilian business rules. It groups every common concern around Brazilian data — validation, formatting, masking, generation, and modeling — into a small, consistent, tree-shakable API.

The core library is published as [`@brutils/core`](https://www.npmjs.com/package/@brutils/core). Framework adapters live alongside it in the monorepo (e.g. `@brutils/react`).

::note
This project is currently under active development and is **experimental**. APIs may change without notice until `v1`.
::

## Design principles

- **`validate()` never throws.** Public validators return `{ success, error }` result objects with typed error codes. They throw only when the _input type_ itself is wrong (e.g. passing a number where a string is expected).
- **Typed errors with `code`.** Every module defines its own `Error` subclass with a `readonly code` property typed as a union of string literals (e.g. `"INVALID_FORMAT" | "REPEATED_DIGITS" | "INVALID_CHECKSUM"`).
- **Strict input, helpful output.** Inputs are accepted as either raw digits or the standard mask — anything else fails fast with `INVALID_FORMAT`.
- **Tree-shakable, ESM-first.** Import only the module you need; the rest is dropped by the bundler.
- **Strict TypeScript.** `strict`, `noUnusedLocals`, `verbatimModuleSyntax` — all on.
