Bem-vindo(a) ao **brutils**, o kit essencial brasileiro para a web moderna.

## O que é o brutils?

`brutils` é um monorepo TypeScript de utilitários para regras de negócio brasileiras. Ele agrupa as preocupações mais comuns em torno de dados brasileiros — validação, formatação, mascaramento, geração e modelagem — em uma API pequena, consistente e tree-shakable.

A biblioteca principal é publicada como [`@brutils/core`](https://www.npmjs.com/package/@brutils/core). Adaptadores de frameworks vivem ao lado dela no monorepo (ex.: `@brutils/react`).

::note
Este projeto está em desenvolvimento ativo e é **experimental**. APIs podem mudar sem aviso até a `v1`.
::

## Princípios de design

- **`validate()` nunca lança exceção.** Validadores públicos retornam objetos `{ success, error }` com códigos de erro tipados. Eles só lançam quando o _tipo do input_ está errado (ex.: passar um número onde uma string é esperada).
- **Erros tipados com `code`.** Cada módulo define sua própria subclasse de `Error` com uma propriedade `readonly code` tipada como uma união de literais (ex.: `"INVALID_FORMAT" | "REPEATED_DIGITS" | "INVALID_CHECKSUM"`).
- **Input estrito, output útil.** Entradas são aceitas como dígitos crus ou na máscara padrão — qualquer outra coisa falha rápido com `INVALID_FORMAT`.
- **Tree-shakable, ESM-first.** Importe apenas o módulo necessário; o resto é descartado pelo bundler.
- **TypeScript estrito.** `strict`, `noUnusedLocals`, `verbatimModuleSyntax` — todos ligados.
