`brutils` é um workspace [pnpm](https://pnpm.io/) gerenciado com [vite-plus (`vp`)](https://viteplus.dev/guide/), que encapsula build, testes, lint e formatação em uma única CLI.

## Layout do monorepo

```bash
brutils/
├── packages/
│   ├── core/                # @brutils/core — a biblioteca principal
│   └── react/               # @brutils/react — adaptadores e hooks para React
├── docs/                    # @brutils/docs — este site (Docus + Nuxt 4)
├── examples/                # Exemplos de uso autocontidos
├── scripts/                 # Scripts do repositório
├── pnpm-workspace.yaml      # Workspace + catalog
└── package.json             # Scripts e devDependencies do root
```

## `packages/core/`

A biblioteca principal. A API pública é organizada em **módulos** de feature em `src/utilities/`.

```bash
packages/core/src/
├── common/                  # Helpers compartilhados (ex.: assert-options, progressive-format)
├── utilities/
│   ├── cpf/
│   │   ├── constants.ts     # Regexes, comprimentos
│   │   ├── types.ts         # Códigos de erro, interfaces de opções/resultados
│   │   ├── utils.ts         # assertValid + a classe Error do módulo
│   │   ├── cpf.ts           # API pública: validate, format, generate, ...
│   │   └── index.ts         # Re-exporta a superfície pública do módulo
│   ├── cnpj/
│   ├── cep/
│   └── ufs/
└── index.ts                 # `export * as cpf from "./utilities/cpf/index"` etc.
```

Todo módulo segue o mesmo formato: um helper estrito `assertValid()`, uma subclasse de `Error` tipada com uma união `code`, e funções públicas que preferem retornar objetos de resultado em vez de lançar exceções.

## `docs/`

Este site. Um projeto [Docus](https://docus.dev) (Nuxt 4) com internacionalização para Inglês e Português Brasileiro.

```bash
docs/
├── content/
│   ├── en/                  # Conteúdo em inglês
│   └── pt-BR/               # Conteúdo em português brasileiro
├── public/                  # Assets estáticos
├── nuxt.config.ts           # Configuração do Nuxt + i18n
└── package.json
```

## Ferramentas: `vp`

Comandos comuns na raiz do repositório:

| Tarefa                                         | Comando             |
| :--------------------------------------------- | :------------------ |
| Instalar dependências                          | `pnpm install`      |
| Rodar o site da documentação em dev            | `pnpm dev`          |
| Formatar o código                              | `pnpm format`       |
| Lint + testes do workspace                     | `pnpm test`         |
| Validação completa (fmt + lint + test + build) | `pnpm ready`        |
| Build de todos os pacotes                      | `pnpm -r run build` |

Dentro de `packages/core/`:

| Tarefa                    | Comando           |
| :------------------------ | :---------------- |
| Rodar todos os testes     | `vp test`         |
| Rodar um teste específico | `vp test cpf`     |
| Build da biblioteca       | `vp pack`         |
| Watch + rebuild ao salvar | `vp pack --watch` |
| Type-check manual         | `tsc --noEmit`    |

## Imports

Sempre importe a partir de `vite-plus` em vez das dependências cruas:

```ts
import { defineConfig } from "vite-plus";
import { expect, test, vi } from "vite-plus/test";
import { defineConfig } from "vite-plus/pack"; // tsdown.config.ts
```
