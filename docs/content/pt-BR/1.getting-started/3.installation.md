## Instale `@brutils/core`

::code-group

```bash [pnpm]
pnpm add @brutils/core
```

```bash [npm]
npm install @brutils/core
```

```bash [yarn]
yarn add @brutils/core
```

::

## Requisitos

- **Node.js** `>= 24.13.1` (alinhado com o `engines` do monorepo).
- **TypeScript** `>= 5` recomendado. `@brutils/core` já inclui as definições de tipo.
- **ESM**. O pacote é apenas ESM (`"type": "module"`).

## Exemplo rápido

```ts [exemplo.ts]
import { cpf, cnpj, cep, ufs } from "@brutils/core";

const resultado = cpf.validate("123.456.789-09");
if (resultado.success) {
  console.log("CPF válido");
} else {
  console.log("Inválido:", resultado.error.code);
  //                                       ^? "INVALID_FORMAT" | "REPEATED_DIGITS" | "INVALID_CHECKSUM" | "UNKNOWN_ERROR"
}

const mascarado = cnpj.format("12345678000195"); // "12.345.678/0001-95"
const gerado = cpf.generate({ formatted: true }); // ex.: "123.456.789-09"
const sp = ufs.get("SP"); // { name: "São Paulo", region: "Sudeste", ... }
const cepValido = cep.validate("01310-100");
```

## Trabalhando no monorepo

Para contribuir, clone o repositório e instale com pnpm:

```bash [Terminal]
git clone https://github.com/youphenrique/brutils.git
cd brutils
pnpm install
```

O monorepo é gerenciado com [pnpm workspaces](https://pnpm.io/) e [vite-plus](https://viteplus.dev/guide/). Para rodar a documentação localmente:

```bash [Terminal]
pnpm dev
```

Esse comando executa o script `dev` de `@brutils/docs` (este site) em <http://localhost:3000>.
